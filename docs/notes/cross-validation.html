NOTE 03 ／ 模型評估 ／ 預估 3 分鐘

交叉驗證：換幾組資料再看看

輪流保留不同資料做驗證，觀察模型表現。

內容查核：2026-11-16

01 / UNDERSTAND

核心概念

已查證概念 · 來源見下方

K-fold 交叉驗證把開發資料分成 K 份，每輪用其中一份驗證，其餘份數訓練，最後彙整各輪分數。

交叉驗證可用於模型選擇，仍應保留最後測試集。時間序列與群組資料需要符合結構的切分策略，不能直接套用一般隨機切分。

02 / PUT IT IN CONTEXT

自編示例：五份輪流驗證

假設 100 筆開發資料可分成五份，每份 20 筆。做 5-fold 時每輪用 80 筆訓練、20 筆驗證，共訓練五次。每一筆在其中一輪擔任驗證資料；它不代表五次使用完全相同的模型，也不代表已完成獨立測試。

教學用假設情境，非實際實驗結果。

03 / WATCH OUT

常見誤解

誤解：做了交叉驗證，就可以反覆用最後測試集調參。更正：最後測試集仍應保留，避免模型選擇依賴測試結果。

04 / KEEP THIS

帶走一句話

讓資料輪流當驗證集，最後測試集仍留到最後。

05 / CHECK YOURSELF

停一下，確認理解。

標準 5-fold 交叉驗證中，每輪有幾份資料用來訓練？

  1. 四份
  2. 一份
  3. 五份
想好再看答案

答案：A．四份

五份中保留一份驗證，其餘四份用來訓練；這個流程輪替五次。
