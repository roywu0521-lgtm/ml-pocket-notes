# 延伸示範：新增第五篇「資料洩漏」

## 實作方式

初始設計包含資料切分、過度擬合、交叉驗證與混淆矩陣四個主題。「資料洩漏」使用同一份 AGENTS.md 與 JSON 資料契約，新增於 `content/notes/data-leakage.json`，order 設為 5，分類設為「資料準備」。

新增內容有來源、查核日期、自編示例與一題三選一；產生器不需要加入依 slug 特判的文章版型。執行 build 後，首頁自動收錄，搜尋資料自動加入，並產生 `docs/notes/data-leakage.html`。規則頁的示範連結指向這篇文章。

## 可重複操作的指令

> 請閱讀 AGENTS.md 與 templates/note.json，新增「特徵縮放」筆記，選用官方來源與真正查核日期，依規則提供自編示例及單一正解測驗。請重新 build、test，並確認新筆記出現在首頁、分類與搜尋結果中。

## 如何重現

複製範本、新增 JSON、依規則填寫、執行 `npm run build` 與 `npm test`。驗證器會阻止缺來源、錯誤日期、重複順序或不存在的延伸閱讀。它不能判斷內容真偽，查證仍是 AI／作者的必要工作。

這份紀錄描述本專案的內容延伸方式，並非宣稱由另一個獨立 AI 工作階段完成的盲測。
